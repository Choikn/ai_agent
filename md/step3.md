# 목표
- 프롬프트 엔지니어링 적용
```
# Role(역할)

# Context(내용)

# Task(실제로 할 일, 지시사항)

# Constraints(제약)
```
- 필요시 퓨샷(샘플 제공) 적용
- 프롬프트의 양식(폼, 형태)는 최적의 답을 얻기 위한 애플리케이션의 핵심 내용 관리
  - 서비스의 핵심 자산 관리해야함

# 구조
```
/
L app/
  L prompts.py  : 프롬프트 구성, 퓨샷
L steps/
  L step3_prompt_engineering.py : 프롬프트 엔지니어링 기술 적용하여 LLM 질의
```

# 실행
```
python -m steps.step3_prompt_engineering
---
prompt = marketing_prompt("AI 고객상담 솔루션", "온라인 쇼핑몰 CS팀")

반복되는 문의에 지친 CS팀, 이제 AI에게 맡기세요.

배송 조회부터 교환·환불 안내까지, 자주 묻는 질문은 AI가 즉시 응답합니다.
상담원은 복잡하고 중요한 문의에만 집중할 수 있어 응답 품질이 올라갑니다.
고객은 기다리지 않고, 팀은 반복 업무에서 벗어납니다.

지금 무료로 도입 상담을 신청해보세요.

---
prompt = marketing_prompt("Enterprise AI Agent", "업무 자동화를 검토하는 운영팀")

반복 업무에 소요되는 시간, 여전히 사람이 직접 처리하고 계신가요?

Enterprise AI Agent는 반복적인 운영 업무를 자동으로 처리하여, 팀이 더 중요한 의사결정에 집중할 수 있도록 돕습니다.

복잡한 시스템 연동 없이, 기존 워크플로우에 자연스럽게 통합됩니다.

운영 효율을 높이고 싶은 팀이라면, 지금이 검토를 시작할 시점입니다.

지금 바로 무료 데모를 신청해 보세요.
```
