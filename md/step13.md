## 📄 상품 하자 환불 정책 (출처: CS-REFUND-2026)

**1. 신청 기간 및 조건**
- 상품 수령 후 **30일 이내** 교환 또는 환불 신청 가능
- 제조상 하자나 기능상 문제가 확인된 경우 적용

**2. 비용 부담**
- 고객에게 귀책사유가 없다고 판단될 경우, **회수 배송비 및 재배송비는 회사가 부담**
- 고객센터는 필요 시 **사진/동영상/제품 상태 확인 자료**를 요청할 수 있음

**3. 환불 처리 절차**
- 반품 상품이 물류센터에 도착하여 **검수 완료 후** 환불 진행
- 검수 시 사용 여부, 구성품 누락, 훼손 여부, 반품 사유 확인
- 정상 반품 확인 시 **원결제 수단 기준 환불** (카드사/PG사 처리 일정에 따라 실제 환불 완료 시점은 차이 발생 가능)

**4. 추가 유의사항**
- 사은품/증정품 포함 시 함께 반환 필요 (미반환·사용 시 금액 차감 가능)
- 세트 상품은 전체 구성 기준으로 반품 여부 판단
- 고객 과실로 인한 훼손·사용 흔적이 명확한 경우 반품이 제한될 수 있음 (단, 이번 건은 제조상 하자로 해당 없음)
